# Vira Forms — فرمساز فارسی مبتنی بر MySQL

طراحی فرم با کشیدن و رها کردن، انتشار خودکار جدول پاسخ‌ها در MySQL و تولید
فایل PHP خودکفا (`index.php`) آماده آپلود روی هاست — همراه با پیامک SMS.ir،
منطق شرطی فیلدها و قالب‌های آماده.

## شروع سریع

```bash
npm install
npm run dev
# http://localhost:3000
```

## پیکربندی (مهم برای گیت‌هاب)

هیچ secretای در کد commit **نمی‌شود**. همه مشخصات حساس را در صفحه
**تنظیمات** داخل اپ وارد کنید (آیکون چرخ‌دنده در داشبورد):

- **اتصال دیتابیس**: هاست، پورت، کاربر، رمز + نام دیتابیس متا (`vira_forms`)
  و دیتابیس جدول پاسخ‌ها (`Forms`) — همراه با دکمه **تست اتصال**
- **پیامک پیش‌فرض SMS.ir**: کلید API و شماره خط

تنظیمات در فایل `data/app-settings.json` روی همین سرور ذخیره می‌شود
(در `.gitignore` است و منتشر نمی‌شود). اگر این فایل وجود نداشته باشد،
اپ از متغیرهای محیطی (`.env.local`) به‌عنوان پیش‌فرض استفاده می‌کند؛
نمونه آن در `.env.example` هست.

دسترسی ریموت MySQL (روی سرور، در phpMyAdmin):

```sql
CREATE USER IF NOT EXISTS 'root'@'%' IDENTIFIED BY '';
GRANT ALL PRIVILEGES ON *.* TO 'root'@'%';
FLUSH PRIVILEGES;
```

## جریان کار

1. **داشبورد** → فرم جدید یا انتخاب از **قالب‌های آماده** (بازدید، ثبت ایده،
   تنیس، ایرهاکی، اکسل…)
2. **بیلدر** → طراحی فیلدها، منطق شرطی، اعتبارسنجی، تنظیمات فرم/پیامک
3. **انتشار** → ساخت خودکار جدول در دیتابیس `Forms` + دانلود `index.php`
4. آپلود `index.php` در پوشه‌ای روی هاست (مثلاً `vira98.ir/signupform`)
5. پاسخ‌ها در جدول MySQL + قابل مشاهده/حذف/خروجی CSV در صفحه پاسخ‌ها
